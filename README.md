# Backend Dy Fy
Sistema para pesquisar e baixar vídeos do YouTube utilizando React e Node.

Hospedado na Render: https://dy-fy.onrender.com

## Tecnologias
- Node JS
- Express
- @distube/ytdl-core
- yt-search

## Instalação
Baixe o projeto
```cmd
git clone https://github.com/JoaoEnrique/dy-fy.git -b backend
```

Para rodar o projeto:
```cmd
cd dy-fy
npm install
npm start
```
